# 刻詠みアラーム サポートサイト

iPhoneアプリ「刻詠みアラーム」のサポート、よくある質問、プライバシーポリシー、音声・クレジットを掲載する静的サイトです。GitHub Pagesで公開しています。

- 構成：HTMLとCSSのみ（JavaScript、Cookie、アクセス解析、外部フォントは使用していません）
- ページ：`index.html`（トップ）、`support/`、`faq/`、`privacy/`、`credits/`
- 共通スタイル：`assets/style.css`
- `.nojekyll`：GitHub PagesのJekyll処理を使わず、ファイルをそのまま公開するための空ファイルです
